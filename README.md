# Cognifyz IT Solutions — Web Development Internship
## Manda Nikitha

This submission contains the complete **Level 1 and Level 2** tasks from the supplied Cognifyz Web Development Internship task document.

## Completed requirements

### Level 1 — Task 1: HTML/CSS
- Simple webpage with a heading, paragraph and image.
- Basic form with one input field and submit button.
- Navigation menu with three links.

### Level 1 — Task 2: JavaScript
- Button changes color when clicked.
- Alert greeting changes according to the current time.
- Calculator adds two numbers and displays the result.

### Level 2 — Task 1: Front-end Frameworks
- Responsive card component containing an image/visual and text.
- Responsive grid layout using Bootstrap.

### Level 2 — Task 2: Responsive Design
- Webpage adapts to different screen sizes using CSS media queries.
- Navigation collapses into a hamburger menu on smaller screens.

## How to run

Each task is independent.

1. Open the task folder.
2. Double-click `index.html`.
3. The Level 2 Task 1 project uses Bootstrap from a CDN, so internet access is recommended for that project.
4. All other task functionality is implemented locally with HTML, CSS and JavaScript.

## Submission note

The project folders are intentionally separated by level and task to make the work easy to inspect and submit.
