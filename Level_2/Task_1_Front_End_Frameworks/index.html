My Learning Topics

These cards are arranged using the Bootstrap responsive grid system.

HTML

HTML is used to create the basic structure of a webpage. It is one of the first technologies I learned in web development.

CSS

CSS is used to style webpages. It helps control colors, fonts, spacing and the overall layout of a website.

JavaScript

JavaScript adds interaction to webpages. It can be used to respond to user actions and make webpages more dynamic.

Responsive Grid

The Bootstrap grid changes according to the screen size. On a large screen, the cards appear in three columns. On smaller screens, they move into fewer columns and finally appear one below another.
